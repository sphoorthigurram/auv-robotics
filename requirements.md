# AUV Robotics Website Rebuild Requirements

## Project Overview

Build a modern, professional, responsive website for a robotics team focused on autonomous underwater vehicles. The new website will replace the current Wix site and should preserve the team's core purpose, important content, calls to action, and contact details while improving the visual design, structure, wording, and overall user experience.

Current website reference:
https://reaftamu.wixsite.com/website

Reference pages reviewed:

- Home
- Vehicles navigation and vehicle history
- Meet the Team
- Achievements
- Sponsors content surfaced on the home page

## Primary Goal

Create a production-ready coded website that presents the robotics team as credible, technically capable, active, and easy to contact. The site should feel custom-built for an autonomous underwater robotics team rather than like a generic template.

## Target Audience

- Prospective team members
- Sponsors and donors
- University stakeholders
- Competition organizers
- Engineering students and faculty
- Visitors interested in autonomous underwater vehicle projects

## Scope

The website should be rebuilt using ReactJS.

The final implementation should use reusable components and a responsive layout that works well on desktop, tablet, and mobile screens.

## Content Requirements

The new site should review and reuse the important information from the existing Wix website, including:

- Team name: TAMU Underwater Robotics (AUV) Team
- Organization affiliation: Women in Robotics, Engineering, and Development (WIRED), Texas A&M University
- Mission: help students apply classroom knowledge to real engineering scenarios, learn multidisciplinary teamwork, build leadership, and gain AUV/ROV experience.
- Autonomous underwater vehicle focus: student-built AUVs for RoboSub and related competitions such as NURC.
- Membership message: open to undergraduate engineering students, with no previous AUV experience required.
- Key metric: 40% of team members start without prior experience building AUVs or similar projects.
- Calls to action: join the team, follow the team, contact the team, support/sponsor the program, and learn about RoboSub.
- Contact/location: Texas A&M University, College Station, Texas; email shown in implementation as reaftamu@gmail.com pending final confirmation.

Content should be rewritten where needed to improve clarity, professionalism, and flow. Do not use lorem ipsum or placeholder marketing copy.

## Design Requirements

The website should have a modern, clean, polished, and professional design. It should avoid a basic template look and should visually reflect robotics, engineering, underwater systems, and technical innovation.

Required design improvements:

- Strong visual hierarchy
- Clear page structure
- Better spacing and alignment
- Improved typography
- Professional color palette
- Modern buttons
- Clean cards and content sections
- Responsive navigation
- Mobile-friendly menu
- Production-ready visual finish

## UX Requirements

The site should make key information easy to find and should guide visitors toward meaningful actions.

Expected user experience:

- Visitors can quickly understand who the team is and what it builds.
- Visitors can navigate between major sections without confusion.
- Sponsors or interested partners can find contact information easily.
- Prospective members can understand the team's work and how to get involved.
- Pages and sections should remain readable and usable on small screens.

## Technical Requirements

- Use React components for repeated sections such as navigation, footer, cards, buttons, and content blocks.
- Use semantic HTML where applicable.
- Implement responsive styling for desktop, tablet, and mobile.
- Keep the code organized and maintainable.
- Avoid unused placeholder content.
- Use accessible color contrast and readable font sizes.
- Ensure images and media are optimized or sized appropriately.

## Suggested Site Structure

The React site should use a streamlined one-page structure with clear anchor navigation:

- Home
- About
- Subteams
- Vehicles
- Team / Officers
- Impact / Achievements
- Recruitment
- Sponsors or Support
- Contact
